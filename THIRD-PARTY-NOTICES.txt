MediaHub download integration

Motrix UI adaptations
Source: https://github.com/agalwood/Motrix
Revision: e17aed07b40f65f17e12795adbffafd3e97774f2 (2.4.5)
Adapted: downloads/filter.ts (tab/search logic), lib/task-views.ts (active
statuses), lib/format.ts (formatProgressPercent), downloads/task-progress.tsx
and status-pill.tsx (DOM ports of progress/status presentation).
MediaHub uses its own plain-JavaScript shell, API and glass styling. It does
not embed the full React application or implement Motrix's plugin platform.
